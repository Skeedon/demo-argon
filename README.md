# ARGON·RND — дизайн-концепт

Демонстрационный адаптивный сайт мастерской аргоновой сварки. **Неофициальный концепт**, не связанный с владельцем мастерской.

## Структура

```text
demo-argon/
├── index.html                  # Главная страница
├── aluminum-welding.html       # Страница услуги
├── assets/
│   ├── css/
│   │   ├── home.css            # Стили главной
│   │   └── service.css         # Стили страницы услуги
│   └── js/
│       └── main.js             # Анимации и мобильная навигация
├── .gitignore
└── README.md
```

## Запуск

Сайт статический, сборка и установка зависимостей не нужны. Откройте `index.html` в браузере или запустите локальный HTTP-сервер:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Редактирование

- Содержимое главной: `index.html`
- Содержимое страницы услуги: `aluminum-welding.html`
- Оформление: `assets/css/`
- Интерактивность: `assets/js/main.js`

Публикация через GitHub Pages: ветка `main`, каталог `/ (root)`.
